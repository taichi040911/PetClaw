# KB96: Claude Codeでキャラデザのブラッシュアップと各コマンドの順次実行ガイド
**バージョン**: 2026年4月最新版
**対象**: 非エンジニア向け（Claude Code + Ralph Loop活用）
**前提KB**: KB00 (PetClaw概要), KB50 (スプライト仕様)

---

## 1. 全体の流れ（非エンジニア向け推奨ワークフロー）

Claude Codeの強みはRalph Loopによる自動反復改善です。
一発で完璧を求めず、「少しずつブラッシュアップ」を繰り返すのがコツです。

### 基本ステップ:
1. **Coworkで企画・プロンプト作成**（レイアウトや方向性を固める）
2. **CodeでRalph Loop起動**（自動で何度も生成・改善）
3. **MCP + Godotで視覚確認**（生成画像をGodotにインポートして確認）
4. **フィードバックをループに反映**（「ここをこう変えて」と指示）

---

## 2. キャラデザブラッシュアップの具体的なRalph Loop設定例

### 基本指示テンプレート（Claude Codeに貼る）:

```
Ralph Loopを活性化してください。
私は非エンジニアなので、ステップごとにわかりやすく説明しながら進めてください。

現在のキャラデザ（[ここに前の生成画像の説明やファイル名]）をブラッシュアップしたいです。
目標: スタイリッシュ2Dピクセルスタイルで、PetClawの[性格: curious / braveなど]を反映した可愛く魅力的なキャラに。
特に[目・表情・粒子エフェクト・服装]を改善。

Leonardo.ai / Tripoで新しいバージョンを生成し、改善点を3つ挙げてから次のプロンプトを提案してください。
MCPでGodotにインポートした視覚確認も行って。

--max-iterations 8
--completion-promise "CHARA_DESIGN_BRUSHUP_DONE"
--temperature 0.7
```

### 具体例（基本ペット → 勇敢進化形）:

```
Ralph Loopを活性化。
現在の基本ペットキャラ（round fluffy blob, big curious eyes, orange cream color）を勇敢進化形にブラッシュアップ。
- 姿勢を力強く、目にはinner fireを追加
- 服装にmetallic accentsを入れ、brave-sparkを反映
- 粒子エフェクトを感情連動で派手に

各イテレーションで生成画像の改善点を説明し、次のプロンプトを提案。
Godotスプライトとして使いやすい形に調整。

--max-iterations 10
--completion-promise "BRAVE_FORM_READY"
```

## 3. 各コマンドを順次実行させる方法（Ralph Loopの高度活用）

Ralph Loopは同じプロンプトを繰り返し投入して自動改善する仕組みです。
順次コマンドを実行させるには、**タスクリスト方式**が効果的です。

### おすすめの順次実行パターン:
1. **タスクリストを作成**（Coworkで先に作る）
2. **Ralph Loopで「タスク1を実行 → 完了したらタスク2へ」と指示**

### 例: キャラデザ全工程を順次実行

```
Ralph Loopを活性化。
キャラデザのブラッシュアップを以下の順序で進めてください。

タスクリスト:
1. 基本形の可愛さ向上（表情・目・シルエット）
2. 勇敢進化形の力強さ追加（姿勢・アクセント・粒子）
3. 好奇心形の遊び心追加（ポーズ・アクセサリー）
4. 生き死に・交配時の表情バリエーション作成
5. Godotスプライトシート対応の最終調整

各タスク完了時に「タスクN完了。次のタスクに進む」と明確に宣言し、改善点を3つ説明してください。
MCPでGodot視覚確認も行って。

--max-iterations 15
--completion-promise "FULL_CHARA_DESIGN_COMPLETE"
```

## 4. 非エンジニア向けTips

- **一回に小さく**: 「全部完璧に」ではなく「まずは基本形の目を良くして」と区切る
- **確認習慣**: 各イテレーション終了後に「この変更のポイントを3つ教えて」と聞く
- **画像フィードバック**: 生成画像をClaude Codeに貼って「この画像を基に改善して」と指示
- **Godot連携**: MCPで「この画像をスプライトとしてインポートしてテストして」と指示
- **停止・調整**: ループ中に `/cancel-ralph` で止め、指示を微調整

### すぐに試せる指示（Claude Codeに貼る）:

```
Ralph Loopを活性化。
キャラデザの基本形をブラッシュアップ。
可愛く感情豊かな表情と、粒子エフェクトの連動を強化。
各イテレーションで改善点を説明し、次のプロンプトを提案。

--max-iterations 8
--completion-promise "BASIC_CHARA_READY"
```
