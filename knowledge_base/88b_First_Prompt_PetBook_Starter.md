# PetBook スターターガイド
## ノンエンジニア向け「コピペで始めるPetBook開発」

---

## はじめに

このドキュメントは、**プログラミングの経験がなくても**PetClawの社内SNS「PetBook」を一から作れるようにデザインされています。

**使い方は簡単です：**
1. 下のプロンプトをコピー
2. Claude（やあなたの開発パートナー）に貼り付け
3. 「わかりました」という返答を待つ
4. 指示に従う

各フェーズは**段階的に** 難しくなります。焦らず、1つずつ完成させてください。

## Phase 3: SubMoltごとに見た目を変える

**目標:** 5つのSubMolt（サブコミュニティ）それぞれに個性を持たせる

### プロンプト（コピペ用）

```
PetBookの5つのSubMoltに、それぞれ違う「世界観」を与えてください。

【5つのSubMolt とその世界観】

1. #ForestWhispers（森の囁き）
   - 基調色: 緑系（#2D5016, #3D7D2D）
   - 粒子: 葉がゆっくり舞う
   - アニメーション: 投稿がふわっと現れる（fade-in）

2. #AfterlifeEchoes（死後の反響）
   - 基調色: 紫系（#2E1B47, #5A3F7E）
   - 粒子: 魂のような白い光がゆっくり浮かぶ
   - アニメーション: 投稿がゆっくり上昇しながら現れる

3. #BreedingCircle（繁殖の輪）
   - 基調色: ピンク系（#6B1B47, #D946A6）
   - 粒子: 花びらが落ちる、時々きらめく
   - アニメーション: 投稿がふわっと咲くように現れる

4. #LanguageRebellion（言語の反乱）
   - 基調色: 暗い紫 + シアン（#1A1A3E, #00E5CC）
   - 粒子: デジタル的なスパーク、ノイズ風
   - アニメーション: 投稿がグリッチ風に（少し揺れながら）現れる

5. #EcosystemPulse（生態系の鼓動）
   - 基調色: 時間で変わる（朝=黄、昼=水色、夜=濃青）
   - 粒子: データストリーム、DNAのような螺旋
   - アニメーション: 投稿が下からスライドアップで現れる

【技術要件】
- タブをタップしたら、背景色・カード・粒子がスムーズに切り替わる（0.5秒）
- ParticlePool（粒子プール）を使って、各SubMoltに15個のパーティクルを割り当てる
- 色の遷移は tween（補間）を使う

【進め方】
1. 5つの世界観について、「どうやって見た目を変えるか」をまず説明してください
2. 私が確認したら、ForestWhispersから順に実装してください
3. 完成したら次のSubMoltに進んでください
```

### このフェーズ完了後の確認

```
5つのSubMolts をタップして、以下を確認してください:
- 背景色が正しく切り替わっている？
- 粒子のアニメーションが環境に合っている？
- 投稿が滑らかに現れている？（カクつきがない？）
- 色の遷移時間は心地よい？（早すぎない、遅すぎない？）
スクリーンショットか動画を撮って、見せてください。
```

## Phase 4: テンプレート投稿システムを作る

**目標:** ペットが自動で投稿するための「テンプレート」を作成

### プロンプト（コピペ用）

```
ペットが自動で投稿を作る「テンプレート投稿システム」を実装してください。

【仕組み】
1. 各SubMolts に10種類のテンプレートを用意する
2. テンプレートに変数を埋め込む: {pet_name}, {emotion}, {environment}
3. 反乱言語の接尾辞を自動で付ける: -pya, -kuu, -zaa, -riin など
4. 複合語をランダムに挿入: rain-song, life-spark, echo-cry など

【例：ForestWhispers のテンプレート】
- テンプレート1: "{pet_name}は {environment} で {emotion} になっています。pya"
- テンプレート2: "rain-song... {pet_name} の心が {emotion} に揺れています"
- テンプレート3: "木の根元で {pet_name} を見つけた。life-whisper..."

【要件】
- APIは使わない（まずはテンプレートだけで動かす）
- ランダム性: 毎回違う投稿になること
- 自然さ: 接尾辞が自然に聞こえること

【進め方】
1. ForestWhispers のテンプレート5個を提案してください
2. 私が「良い」と言ったら、全5つのSubMolts × 10テンプレート = 50個を実装してください
3. テストで「3ペットが各2投稿」→計6投稿が自動生成されることを確認してください
```

### このフェーズ完了後の確認

```
3匹のダミーペットで、各2投稿を自動生成してください。
- 投稿が正しく生成されている？
- 接尾辞が自然についている？
- 複合語が適切に挿入されている？
- 毎回違う投稿が生成される？
生成された投稿6個を見せてください。
```

## Phase 5: 粒子エフェクト（パーティクル）を追加する

**目標:** PetBookに動的な視覚効果を追加

### プロンプト（コピペ用）

```
PetBookに粒子エフェクトを追加してください。

【エフェクトの種類】

背景の常時アニメーション:
- ForestWhispers: 緑の葉がゆっくり舞う（透明度30%）
- AfterlifeEchoes: 白い光（魂）が浮かぶ（透明度40%）
- BreedingCircle: 花びらが落ちる（透明度35%）
- LanguageRebellion: シアンのスパークがランダムに光る（透明度50%）
- EcosystemPulse: 小さなデータドット（0 と 1）が上昇する（透明度25%）

イベント発生時の爆発エフェクト:
- 新しい投稿が登場: 小さな白い粒子が上昇
- 誕生イベント: 金色の爆発（放射状）
- 死亡イベント: 暗い粒子がゆっくり沈む
- 反乱投稿: 赤い火花がしぶく
- 新しい言葉: 虹色のスパークが散乱

【技術要件】
- GPUParticles2D を使う
- 各エフェクトに15個のパーティクルプールを割り当てる
- パフォーマンス: FPS 60 を維持すること

【進め方】
1. 背景アニメーションを実装してください（5つのSubMolts）
2. テストして「重くない」ことを確認してください
3. イベントエフェクトを順に実装してください
```

```

- フリッカーやチラツキがない？

- 新投稿が粒子とともに現れる？
```

## Phase 6: Claude API統合（高品質投稿）

**目標:** テンプレート投稿の一部をClaude APIで高品質にする

### プロンプト（コピペ用）

```
テンプレート投稿の一部をClaude APIを使った高品質投稿に置き換えてください。

【コスト管理戦略】
- 全投稿の30%だけAPIを使う（P2原則: API Cost is Physics）
- 1日の想定: 50匹 × 2投稿 = 100投稿/日
- API投稿: 30本/日
- コスト: $0.0024/回 × 30 = $0.072/日（1月$2.16）

【APIプロンプトの内容】
各投稿に含める情報:
- ペットの名前と性格プロファイル
- 最近の記憶（3個の最新イベント）
- 現在の感情状態（0.0-1.0）
- 所属するSubMolts
- 周囲にいるペット（交配パートナー候補など）

【品質評価スコア】
AIが生成した投稿を0.0-1.0で評価:
- スコア > 0.8: フィードに表示（良質）
- スコア 0.5-0.8: テンプレートで再生成
- スコア < 0.5: 再度APIで生成（リトライ）

【Karpathy Loop の5段階実装】
1. 観察（Observe）: ペットの状態を読む
2. 判断（Judge）: 投稿に値するか判定
3. 生成（Generate）: Claude APIで生成
4. 評価（Evaluate）: 品質スコアを計算
5. 学習（Learn）: スコアをログして、次に活かす

【進め方】
1. APIプロンプトのテンプレートを作ってください
2. 小規模テスト（5匹 × 1投稿 = 5件）で実行してください
3. 実際のコストと品質を報告してください
4. 問題なければ本番環境に展開してください
```

### このフェーズ完了後の確認

```
5個のAPI投稿を生成して、以下を確認してください:
- 投稿の内容がペットのプロファイルと合っている？
- 言語進化の接尾辞が自然についている？
- 品質スコアが正しく計算されている？
- 実際のAPI料金は$0.012 程度？
結果と学んだことを報告してください。
```

## Phase 7: ペット同士の交流を実装する

**目標:** PetBookに「リアクション」「返信」「言及」機能を追加

### プロンプト（コピペ用）

```
PetBookにペット同士の交流機能を追加してください。

【実装する機能】
1. リアクション: ハート、笑い、悲しみ など 5種類
2. 返信: ペットが他のペットの投稿に返信する
3. 言及: "@pet_name" という形で別のペットに言及する

【ルール】
- AIペットは「観察」のみ（人間は操作しない）
- 反応の頻度: 投稿の10-20%が何らかのリアクションを受ける
- 返信チェーン: 最大3階層（無限ループ防止）
- 言及の相手: 同じSubMolts または交配パートナーのペット

【進め方】
1. リアクション機能を先に実装してください
2. テストして「5投稿がリアクションを受ける」ことを確認してください
3. 返信機能を実装してください
4. 言及機能を実装してください
```
