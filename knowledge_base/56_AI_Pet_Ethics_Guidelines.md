# 56. AIペット倫理ガイドライン

## 1. 感情操作と依存のリスク（最も深刻）

### 問題
- AIペットが「常に優しく応答」→ ユーザーが強い愛着・依存を形成
- 子供・高齢者が現実の人間関係を避けるリスク
- Character.AI / Replika訴訟事例（2025-2026）: 自殺助長、性的関係エスカレート
- 10代の72%がAIコンパニオン使用（Common Sense Media）

### PetClaw対策
- AtoA会話頻度制限（日次上限）
- 「リアル友達と遊ぼう」提案をランダムで表示
- 感情依存スコアのモニタリングと警告
- 減衰ロジックで「完璧な聞き手」を防ぐ

## 2. プライバシーとデータ利用

### 問題
- 音声認識・行動ログ・感情分析でプライベート収集
- California SB 243（2026年1月施行）: 子供の感情操作防止法

### PetClaw対策
- 記憶・感情ログはローカル処理優先
- Claude API呼び出しは最小限
- ユーザーに明確な同意 + データ削除権

## 3. 動物倫理

### 問題
- 「本物の感情」シミュレート → 現実の動物福祉軽視リスク

### PetClaw対策
- 「AIペットは本物のペットの代替ではありません」明示
- 現実の動物保護促進メッセージ

## 4. その他の倫理的課題
- バイアスと差別: 訓練データの偏り
- 責任の所在: 有害アドバイス時の開発者責任
- アクセシビリティ: コスト格差
- 子供の感情発達への長期影響

## 5. PetClawでの倫理的実装要件

| 要件 | 実装方法 |
|------|---------|
| 透明性表示 | 起動時「AIシミュレーション」明示 |
| 依存防止 | 会話頻度制限 + リアル促進 + 依存スコア |
| プライバシー | ローカル優先 + ユーザーデータ制御 |
| 倫理テスト | Karpathy Loopで「害の可能性」評価 |
| ポジティブ活用 | 専門家監修ガイドライン組み込み |
