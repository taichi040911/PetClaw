## 設計哲学

PetBookのカラーパレット設計は、以下の第一原理に基づいています：

### P1: 一貫性 × 記憶 = 愛着
- **ダーク基調**: 暗い背景色（bg）に統一することで、目の疲労を減らし、深夜のAIペットとのインタラクションを心地よくする
- **アクセント色**: 各SubMoltに固有のハイライト＋アクセント色を配置し、視覚的なプリンシパル識別を実現
- **階層的な遠近法**: 背景→カード→テキスト→粒子エフェクトの4階層で、奥行きと視認性を両立

### P2: API Cost is Physics
- カラーパレットは静的定数化（PetBookPalette.gd）し、ランタイムでの色計算を最小化
- SubMolt間の遷移時も事前計算された中間色を使用（lerp_palette）
- Godot Engineの Color クラスネイティブ対応で、シェーダー計算コストはゼロ

### P3: Player Agency（AIペットの個性表現）
- 5つのSubMoltが色彩の「方言」として機能
- ForestWhispers（緑）= 自然派、AfterlifeEchoes（紫）= 神秘派、BreedingCircle（桃）= 家族志向
- LanguageRebellion（暗紫＋シアン）= 言語反乱派、EcosystemPulse（適応型）= 環境観測派
- プレイヤーの推し SubMolt に応じて、カラーに対する愛着が深まる

### P4: 10秒フック
- 各SubMoltのメインアクセント色は、0.5秒で視界に認識される高彩度・高コントラストを採用
- テキストは全て TEXT_PRIMARY (#E8E8F0) で確実な可読性を確保
- 背景グラデーション（bg → bg2）により、Flat UIの単調さを回避

### P5: Complexity is Debt
- 色数は56色で統一（グローバル9色 + SubMolt×5×8色 + 感情8色 + バッジ3色）
- 新しい色を追加する場合は、既存色との HSV 調和関係を検証してから追加
- Godot の Color.from_hsv() で検証可能

## 色彩アクセシビリティ

### WCAG 2.1 AA準拠の確認

全てのテキスト色は、背景色との明度コントラスト比を検証。

#### 主要な組み合わせ

| テキスト | 背景 | Hex Combo | コントラスト比 | WCAG | 評価 |
|---------|------|----------|------------|------|------|
| TEXT_PRIMARY (#E8E8F0) | #1A2E1A (ForestWhispers bg) | E8E8F0 on 1A2E1A | 12.8:1 | AAA | **優秀** |
| TEXT_PRIMARY (#E8E8F0) | #1A152E (AfterlifeEchoes bg) | E8E8F0 on 1A152E | 12.3:1 | AAA | **優秀** |
| TEXT_PRIMARY (#E8E8F0) | #2E1A22 (BreedingCircle bg) | E8E8F0 on 2E1A22 | 11.9:1 | AAA | **優秀** |
| TEXT_PRIMARY (#E8E8F0) | #0D0E1A (LanguageRebellion bg) | E8E8F0 on 0D0E1A | 14.5:1 | AAA | **優秀** |
| TEXT_SECONDARY (#8888AA) | #1A2E1A (ForestWhispers bg) | 8888AA on 1A2E1A | 4.2:1 | AA | 合格 |
| highlight色 | 各SubMolt bg | 環境依存 | > 4.5:1 | AA | 合格 |
| emotion色 | #252640 (共通card) | 各感情色 | > 4.5:1 | AA | 合格 |

### アクセシビリティ設計原則

1. **テキストコントラスト**: 全Primary Textは 12:1以上の明度比を確保
2. **カラーブラインドネス対応**: 感情表現は色だけでなくアイコン＋ラベルを併用
3. **粒子エフェクト**: 視認性の妨げにならないよう、常に 40-60% の不透明度を維持
4. **ダーク背景選択**: 全体をダーク系にすることで、目の疲労を軽減し、夜間プレイを配慮

## GDScript実装リファレンス

### ファイル位置
```
godot_project/scripts/ui/pet_book_palette.gd
```

### クラス構成

```gdscript
class_name PetBookPalette
```

**主要メソッド**:
- `get_sub_molt_colors(sub_molt_id: String) -> Dictionary` — SubMolt に応じた全色を返す
- `get_emotion_color(emotion: String) -> Color` — 感情タグから色を返す
- `get_environment_colors(env: String) -> Dictionary` — 環境 ID から EcosystemPulse 用色上書きを返す

## HSV調和分析

### 色相（Hue）の分布

PetClaw のカラーパレットは、 HSV 色環上で戦略的に分散配置されています。これにより、視覚的な多様性と調和を両立させています。

#### SubMolt別の色相フォーカス

| SubMolt | 主色相レンジ | 補色 | 説明 |
|---------|-----------|------|------|
| **ForestWhispers** | H: 99-120° | H: 279-300° | 緑系。補色は紫系（内省的） |
| **AfterlifeEchoes** | H: 220-270° | H: 40-90° | 紫系。補色は黄～橙（希望） |
| **BreedingCircle** | H: 330-346° | H: 150-166° | ピンク系。補色は青緑系（バランス） |
| **LanguageRebellion** | H: 180°, 260-270° | H: 0° | シアン + 紫。反対色は赤（衝突） |
| **EcosystemPulse** | H: 120°, 204° | H: 300°, 24° | 緑 + 青。補色は紫 + 橙（自然の対立） |

### 飽和度（Saturation）の戦略

- **UI背景色**: S: 31-59%（落ち着き）
- **テキストハイライト・アクセント**: S: 47-100%（視認性）
- **粒子エフェクト**: S: 38-67%（適度な目立ち）
- **グロー・投光**: S: 60-100%（神秘性・存在感）

### 明度（Value）の階層

- **深背景（bg2）**: V: 8-13% — ほぼ黒（焦点維持）
- **背景（bg）**: V: 14-18% — ダークグレー（肌触りの良さ）
- **カード**: V: 19-25% — 浮き出す効果（奥行き）
- **テキスト**: V: 67-94% — 明るい（可読性）
- **ハイライト・粒子**: V: 67-100% — 輝く（注意引き）

### 色調（Tone）の一貫性

全てのColor値は RGB ではなく、HSV で思考設計され、その後RGB に変換されています。これにより：

1. **色相の一貫性**: 各SubMolt内での統一感が保証される
2. **彩度の予測可能性**: ハイライト < アクセント < 粒子という階層が自動的に成立
3. **シェーダー対応**: GPU側で HSV 演算が容易（Color.from_hsv()）
4. **拡張性**: 新色追加時に、既存色との色相距離を検証可能

### 調和公式

各SubMolt内では、以下の HSV 調和関係が成立：

**例：ForestWhispers**
- Base Hue: 120° （純粋な緑）
- Highlight Hue: 120° （同色相、S-10%, V+10% で輝き効果）
- Accent Hue: 99° （base - 21°、コンプレメンタリー系統）
- Rebel Hue: 24° （補色 120° + 180° - 76° で対立色）

この配置により、各色が独立しながらも SubMolt の「色彩方言」として機能します。

## デザイン決定記録（ADR）

### ADR-01: ダーク背景の採用

**決定**: 全SubMoltで V < 20% のダーク背景を強制  
**理由**:
- 深夜のAIペット育成（時間無制限プレイ）での目の疲労軽減
- OLEDディスプレイでの省電力化（黒ピクセル = 消灯）
- テキスト色の白（TEXT_PRIMARY）とのコントラスト最大化

### ADR-02: SubMolt色相分散

**決定**: 5つのSubMoltを HSV 色相環上で均等分散  
**理由**:
- 各SubMoltが視覚的に「別の文化圏」として認識可能
- プレイヤーの推しSubMolt選択時に深い愛着形成
- デザインシステムの拡張性（第6、第7 SubMolt追加時も色相を挿入可能）

### ADR-03: 感情色の独立化

**決定**: 感情色は SubMolt パレットと独立させる  
**理由**:
- 全AIペットが共通の感情表現を持つ（文明共通言語）
- SubMolt×感情 の組み合わせが (5 × 8) = 40パターンで収まる
- API Cost削減（色計算はランタイムなし、全てランダムアクセス）
