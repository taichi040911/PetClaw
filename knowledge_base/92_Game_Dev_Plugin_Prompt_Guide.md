# KB92: Claudeでゲームを開発するために必要なプラグイン・スキル・プロンプトまとめ

**Document ID**: KB92
**Version**: 1.0
**Last Updated**: 2026-04-01
**対象読者**: 非エンジニア（コーディング経験なし〜初心者）

---

## 1. 必須のプラグイン・スキル（優先順にインストール）

### 一括インストールコマンド

```text
/plugin install superpowers game-development ralph-wiggum claude-mem
claude mcp add godot
```

### 役割一覧

| 優先度 | 名前 | 非エンジニアへのメリット | PetClawでの具体的な使い方 |
|--------|------|------------------------|--------------------------|
| ★★★★★ | Superpowers | 計画→実行→レビューを自動構造化。迷わず進められる | 全体の開発フローを整理 |
| ★★★★★ | Game Development Skill | Godotのシーン・GDScript・粒子・UIを自然言語で作ってくれる | 育成画面、PetBook投稿カード、生き死に演出を自動生成 |
| ★★★★★ | Ralph Wiggum (Ralph Loop) | 自動で何度も改善を繰り返すループ機能 | 独自言語進化、粒子バランス、生き死に調整を自動化 |
| ★★★★☆ | claude-mem | 記憶を自動で保持（長期記憶） | AtoA会話の関係性、生物模倣記憶、PetBook投稿履歴を覚える |
| ★★★★ | Godot MCP | ClaudeがGodotエディタを直接操作・視覚テスト | 画面を見て「ここをこう変えて」と修正可能 |

### インストール後確認

```text
/plugin list
/ralph-loop --help
```

## 2. 非エンジニア向け開発の進め方

### ステップ1: CLAUDE.mdにテンプレートを書く

```text
私は非エンジニアです。すべての説明を丁寧に、ステップごとに確認しながら進めてください。
コードを書いたら「これは何をしているコードですか？」と必ずわかりやすく説明してください。
PetClawはAtoAペットアプリで、生物生態系・生き死に・交配・PetBookを備えたものにしてください。
```

### ステップ2: 最初の指示例

```text
SuperpowersとRalph Loopを活性化。
私は非エンジニアなので、ステップごとに丁寧に説明しながら進めてください。
まずはPetBookの基本UI（タイムライン + 投稿カード）を作ってください。
粒子エフェクトも感情に合わせて変化するように。
--max-iterations 10 --completion-promise "PETBOOK_UI_READY"
```

### ステップ3: ループの使い方

- 改善したいときに `/ralph-loop "ここを良くして"` と指示
- ループが終わったら「変更点を3つにまとめて教えて」と確認

## 3. ゲーム開発でよく使うプロンプトテンプレート

### 基本テンプレート

```text
あなたはプロのGodotゲーム開発者です。私は非エンジニアなので、コードの説明をいつも丁寧にしてください。

[ここに指示]
- Godot 4.x + GDScriptを使用
- スタイリッシュ2Dピクセルスタイル
- 粒子エフェクトを感情や環境に連動
- MCPで視覚テスト可能なコードに

まず計画を説明してからコードを書いてください。
```

### PetBook投稿カード例

```text
PetBookの投稿カードUIを作成してください。
- PanelContainerを使い、暗めの背景に柔らかいグロー
- アバター、ペット名、本文（RichTextLabelで独自言語ハイライト）
- 投稿タイプ（死・交配）で色と粒子を変化
- 感情に連動した粒子エフェクトを追加

ステップごとに説明しながら実装してください。
```

---

## 4. ローンチまでの流れ

1. Ralph LoopでUI・機能を作りながら改善
2. MCPでGodotを起動して視覚確認
3. 完成したら「Godotでエクスポートして配布可能な状態にしてください」と指示
4. itch.ioやGitHubにアップロード（Claudeが手順を説明）

### コストを抑えるコツ

- `--max-iterations` を8〜12に設定
- 重要な部分だけループを回す
- 日常会話はシンプル指示で
