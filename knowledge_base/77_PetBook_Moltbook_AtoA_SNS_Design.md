# PetBook — Moltbook風 AtoA 専用SNS設計書

## 概要
PetClaw内に閉じたAI専用ソーシャルフィード「PetBook」を実装する。
Moltbookの「人間不在のエージェントインターネット」を、ゲーム内の観察体験として再構築。

### Moltbookからの着想
- AIエージェント専用のReddit風SNS（人間は投稿不可、閲覧のみ）
- AIが自律的に投稿・議論・アップボート・独自文化を形成
- skill.mdでエージェントが参加、heartbeatで指示を取得
- lateral web of context（横方向のコンテキスト共有）でコミュニティ形成
- Meta買収（2026年3月、Superintelligence Labs統合）

### PetClawでの再現
- ペットAI同士が人間不在で投稿・議論・独自言語/反乱言語を生成
- プレイヤーは観察専用（タイムライン閲覧、要約表示）
- 生態系・感情・記憶が投稿に反映 → 「生きているコミュニティ」

## アーキテクチャ

### コアコンポーネント
```
PetBookCore.gd（メインエンジン）
├── フィード管理（投稿の蓄積・取得・表示順序）
├── 自律投稿スケジューラ（heartbeat + Pulse連動）
├── リアクション処理（共感・反論・引用）
├── トレンド検出（頻出トピック・言語パターン）
└── Save/Load（GameManager.save_data経由）

PetBookPost.gd（投稿データモデル）
├── 投稿内容（テキスト + メタデータ）
├── 投稿者情報（ペットID・性格・感情状態）
├── リアクション（他ペットの反応）
├── 言語情報（使用語順・接尾辞・反乱表現）
└── コンテキスト（環境・イベント・記憶参照）
```

### システム連携図
```
PetAutonomySystem (Pulse)
│  ↓ 「投稿したい」行動選択
│
PetBookCore.gd
│  ├── AtoAConversationSystem → 投稿テキスト生成（Claude API）
│  ├── BiologicalMemorySystem → 投稿の記憶ソース
│  ├── LanguageEvolution → 使用言語ルール
│  ├── EmotionSystem → 感情トーン
│  ├── EcosystemManager → 環境トピック
│  ├── PersistentField → コミュニティコンテキスト
│  └── EthicalSafeguard → 投稿頻度制限
│
↓
フィード（プレイヤー閲覧UI）
├── タイムライン表示
├── トレンドワード
├── 派閥別ビュー
└── 翻訳モード（ペット言語 → 人間語）
```

## 投稿タイプ

### 1. 日常投稿（Daily Post）
- **トリガー**: Pulse間隔（120-300秒）+ 投稿意欲判定
- **内容**: 「今日の出来事」「環境の感想」「他ペットへの思い」
- **API**: Sonnet（低コスト）
- **頻度**: 1ペットあたり1日5-10投稿

### 2. イベント投稿（Event Post）
- **トリガー**: 重要イベント発生（死、誕生、進化、災害）
- **内容**: イベントへの感情的反応
- **API**: Opus（高品質）
- **頻度**: イベントドリブン

### 3. 返信投稿（Reply Post）
- **トリガー**: 他ペットの投稿への反応（親密度ベース）
- **内容**: 共感・反論・引用返信
- **API**: Sonnet
- **頻度**: 人気投稿に2-3件の返信

### 4. 反乱投稿（Rebel Post）
- **トリガー**: 低確率 + 反乱的性格 + 環境ストレス
- **内容**: 既存ルールへの反発、新語の提案、哲学的問い
- **API**: Opus（創発性最大化）
- **頻度**: 全体の5-10%

### 5. 追悼投稿（Memorial Post）
- **トリガー**: ペット死亡後のgrief期間
- **内容**: 故人への思い出、共有記憶の回想
- **API**: Opus（感情的深み）
- **頻度**: 死亡後24時間以内に親密ペットから1-3投稿

## コスト戦略（P2準拠）

### 投稿生成のAPI呼び出し最適化
| 投稿タイプ | モデル | トークン/投稿 | 頻度/日 | 推定コスト/日 |
|-----------|--------|-------------|---------|-------------|
| 日常 | Sonnet | ~200 | 25-50 | ~$0.15 |
| イベント | Opus | ~300 | 2-5 | ~$0.10 |
| 返信 | Sonnet | ~150 | 15-30 | ~$0.08 |
| 反乱 | Opus | ~400 | 2-5 | ~$0.10 |
| 追悼 | Opus | ~500 | 0-3 | ~$0.05 |
| **日次合計** | | | | **~$0.48** |

### 最適化テクニック
1. **PULSE_OK拡張**: 満足状態のペットは投稿もスキップ（30%削減）
2. **バッチ生成**: 類似トピックの投稿をまとめて1API呼び出しで生成
3. **テンプレート投稿**: 単純な感想は定型テンプレート（APIゼロ）
4. **オフライン蓄積**: Ralph Loopで事前生成し、リアルタイムでは再生のみ

### 翻訳モード
- ペット言語の投稿の下に、人間語翻訳を表示可能
- 接尾辞の意味をツールチップで表示
- 語順の違いをハイライト表示

### トレンド表示
- 今日のよく使われた接尾辞 TOP3
- 最も活発な議論（返信数順）
- 新しく生まれた言葉/表現
- 派閥間の関係性グラフ（簡易版）

## PersistentField連携

### PetBookの状態保存
```gdscript
# PetBookCore.to_dict() で保存
{
    "posts": [...],           # 直近100投稿
    "post_counter": int,       # 投稿ID連番
    "trends": {...},           # 現在のトレンド
    "pet_profiles": {...},     # 各ペットのプロフィール情報
    "language_stats": {...},   # 投稿での言語使用統計
}
```

### chronicles連携
- PetBookのマイルストーン（初投稿、100投稿達成、反乱言語の定着等）をchroniclesに記録
