# 63. Cotomo・たまごっち風 育成ゲーム開発・UI/UXガイド

## 1. 参考タイトル分析（2026年最新）

### Cotomo (Ludens AI, CES 2026)
- 温かみのあるモバイルAIロボットペット
- 家の中を自律的に動き回り、声・タッチに反応
- 感情表現（目・動き・音）が強い
- 「一緒にいる心地よさ」を重視
- UIはシンプル、アプリ連携でステータス確認・世話コマンド

### 現代たまごっち (Tamagotchi Uni / 2026復刻版)
- 大画面 + Wi-Fi連携コミュニティ
- アイコン中心のシンプルナビゲーション
- カラフルなピクセルアニメ
- 即時反応の世話アクション
- 成長段階で画面レイアウト変化

### PetClawへの示唆
- Cotomo風: 感情表現の豊かさ + 自律行動
- たまごっち風: シンプルUI + 成長のドラマ
- 独自: AtoA会話・記憶・性格進化の自然な統合

## 2. UI/UXレイアウト設計

### メイン画面構成
```
┌──────────────────────────────────────┐
│  [HP] [Energy] [Mood] [Affection]    │ ← ステータスバー（アイコン+ミニバー）
├──────────────────────────────────────┤
│                                      │
│         ┌──────────────┐             │
│         │              │             │
│         │   Pet Live   │             │ ← ペットライブビュー（中央）
│         │    View      │             │    Cotomo風に動き回るアニメ
│         │              │             │    粒子エフェクト常時表示
│         └──────────────┘             │
│                                      │
│  ┌─────────────────────────────┐     │
│  │ AtoA会話ログ（オーバーレイ） │     │ ← 下部に薄く表示
│  └─────────────────────────────┘     │
├──────────────────────────────────────┤
│  [Feed] [Clean] [Play] [Train] [A2A] │ ← 行動メニュー（アイコンタイル）
└──────────────────────────────────────┘
```

### デザイン原則
1. **32×32ピクセルベース**: クリーンなドット絵 + 微かなグロー/影
2. **性格反映アニメ**: 勇敢→力強い動き、好奇心→粒子多め
3. **トランジション**: ピクセルシェイク + 粒子でシームレス
4. **色彩**: HSV計算で感情→色をリアルタイム反映
5. **タッチ最適化**: ボタン44px以上、ワンタップで世話完了

## 3. 画面遷移フロー

```
メイン画面
├── Feed → 餌選択（オーバーレイ）→ 食べるアニメ → 粒子 → AtoA反応
├── Clean → 掃除アニメ → キラキラ粒子 → ステータス更新
├── Play → ミニゲーム選択 → 遊びアニメ → 粒子 → AtoA「楽しかった！」
├── Train → 訓練アニメ → エネルギー粒子 → 進化ポイント表示
├── A2A Chat → 会話ログ全画面 → リアルタイムAtoA観察モード
├── Status → 詳細ステータス + 性格レーダーチャート + 記憶リスト
├── Evolution → 進化ツリー表示 + 現在位置 + 次の条件ヒント
└── Community → Moltbook観察画面（コミュニティ全体俯瞰）
```

## 4. 視覚フィードバック設計

### 世話アクション別アニメ
| アクション | ペットアニメ | 粒子 | 音響 | 画面効果 |
|-----------|------------|------|------|---------|
| Feed | 嬉しそうに食べる | ハート（暖色） | もぐもぐ音 + チャイム | なし |
| Clean | 気持ちよさそう | バブル（シアン） | シャワー音 + キラキラ | 微かな輝き |
| Play | 飛び跳ねる | 星（虹色） | 楽しい音楽 | 微振動 |
| Train | 力を込める | エネルギー波（橙） | 力強いSE | 画面フラッシュ |
| Medicine | 少し嫌がる→安堵 | 癒し光（緑白） | 柔らかいチャイム | なし |

### 感情状態の常時表示
- ペットの頭上に小さな感情アイコン（支配的感情）
- 背景色がゆっくりと感情HSVに連動
- 粒子の密度・色が感情に応じて変化
- AtoAログの文字色が感情で変わる
