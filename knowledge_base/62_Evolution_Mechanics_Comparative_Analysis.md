## 2. PetClaw進化設計原則

### たまごっちから取り入れるもの
- 世話品質が進化に直結する「因果の明確さ」
- 段階的成長の視覚的満足感
- 失敗（死）のリスクによる緊張感

### デジモンから取り入れるもの
- 複数の進化分岐による「唯一性」の感覚
- 努力の蓄積が形になるドラマ
- 条件の透明性（ある程度ヒントを出す）

### ムシキングから取り入れるもの
- 派手な演出による興奮
- 収集・コンプリートの楽しさ
- バトルを通じた進化の動機付け

## 3. PetClawの進化トリガー設計

### 基本条件（AND条件）
```
evolution_readiness >= threshold（段階ごとに異なる）
AND age >= minimum_age
AND overall_condition >= "良好"
```

### 分岐条件（性格・感情ベース）
| 分岐先 | 主要条件 | 補助条件 |
|--------|---------|---------|
| Nature Form | curious > 0.6 | Forest環境での滞在時間 |
| Ocean Form | calm > 0.6 | Sea環境 + affection > 0.5 |
| Shadow Form | brave > 0.6 | Ruins環境 + fear経験 |
| Social Form | affectionate > 0.6 | AtoA会話回数上位 |
| Warrior | brave最高 + Train回数 | バトル勝率 > 60% |
| Scholar | curious最高 + 記憶数 | 言語進化マイルストーン |
| Healer | calm + affectionate | Medicine使用回数 + 他ペットケア |
| Trickster | playful最高 | 独自言語語彙数 > 20 |

### AtoA連動の特殊進化
- **絆進化**: 特定ペアの好感度が最大値 → 同時進化イベント
- **コミュニティ進化**: 派閥リーダーになると特殊形態が解放
- **言語進化**: 独自言語がStage 4以上で「文化的進化」ルート開放

## 4. 進化演出の設計

### 段階別演出パラメータ
| 進化段階 | 粒子量 | 画面効果 | 演出時間 |
|---------|--------|---------|---------|
| Egg→Baby | 100 | 白い光 + 殻割れ | 3秒 |
| Baby→Child | 200 | 色付き光 + 成長波紋 | 4秒 |
| Child→Teen | 400 | 派手な粒子嵐 + 画面揺れ | 5秒 |
| Teen→Adult | 600 | 全画面エフェクト + 性格色爆発 | 7秒 |
| Adult→Elder | 300 | 静かだが荘厳な光 + 記憶フラッシュ | 10秒 |

### 感情連動演出ボーナス
- 進化時の感情が高い → 粒子量 ×1.5、演出時間 +2秒
- 他ペットが見守っている → 祝福粒子追加
- 長期記憶にある相手がいる → 特別な演出テキスト
