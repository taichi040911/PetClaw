## 6. 成功の確認方法

**どの実装を選んでも、以下の確認項目をチェックしてください**:

### A. ファイル構造
```
godot_project/
├── scenes/
│   └── [新規作成されたシーンファイル]
├── scripts/
│   └── [新規作成された GDScript ファイル]
└── project.godot [更新されている]
```

### B. Godot エディタ内
- [ ] シーンが登録されている（Scene ツリーに表示）
- [ ] エラーが出ていない（Output ウィンドウで確認）
- [ ] 再生（▶ ボタン）で画面が表示される

### C. 機能動作
- [ ] 画面要素がすべて表示されている
- [ ] インタラクション（クリック/スクロール）が反応する
- [ ] ステータス数値がリアルタイム更新される

### D. コード品質
- [ ] `class_name` が宣言されている
- [ ] 型注釈がある（`:String`, `:int` 等）
- [ ] `to_dict()` / `from_dict()` メソッドがある
- [ ] シグナルベース設計が使われている

すべて満たしていれば、**Phase 1 は成功です**。

## 7. よくある問題と解決方法

### Q1: Godot エディタで「Script not found」エラーが出る
**A**: クラスパス `class_name` が正しく設定されているか確認してください。
```gdscript
class_name PetBookFeed  # ← ファイル名と一致すること
extends Control
```

### Q2: ボタンを押しても何も起きない
**A**: シグナルが接続されているか確認してください。
```gdscript
button.pressed.connect(_on_button_pressed)
```

### Q3: スクリプトが重い / フレームレートが落ちる
**A**: Ralph Loop で「パフォーマンス最適化」を優先度に加えてください。仮想スクロール等が提案されます。

### Q4: 日本語ラベルが表示されない
**A**: フォント設定を確認してください。Godot 4.x は デフォルトフォントで日本語をサポートしていますが、必要に応じて Noto Sans JP をインポートしてください。
