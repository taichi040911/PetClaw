# PetClaw 3コア機能改善プロンプト集

## はじめに

このドキュメントは、PetClawの3つのコア機能（生き死に、独自言語進化、交配）を改善するためのプロンプト集です。各プロンプトはそのままコピーして、Claude AIや開発パートナーに貼り付けて使えます。

改善のたびに、プロンプトの内容をカスタマイズしてください。数値や演出内容は、あなたのビジョンに合わせて変更してOKです。

---

```
改善案:
- 暗い紫または青の粒子がゆっくり上昇する（3秒かけて消える）
- その間、BGMが静かに切り替わる（可能であれば）

- 他のペット（コミュニティの）が数分以内に追悼リアクションを返す
```

## 独自言語進化改善プロンプト

### 1. 接尾辞の自然な定着を促す

```
PetClawの言語進化で、接尾辞がもっと自然に定着するようにしてください。

現在の仕様:
- ペットが新しい接尾辞を生成する
- Hebbian強化ルールで他のペットに伝播する
- [現在の伝播率と世代数を記入]

改善案:
- 接尾辞が「使い便利な」形態のみ定着する
  （例："-sky"は多くの単語に付きやすいが、"-xth"は付きにくい）
- 同じ接尾辞が複数のペット（独立した系統）で同時進化したら、「普遍的」とマーク
- コミュニティ全体の接尾辞使用頻度を #LanguageTrendsで投稿
- 世代ごとに「このシーズンの最も流行った接尾辞」をランキング表示

接尾辞の選別メカニズムと、Hebbian強化の調整パラメータを説明してください。
```

### 2. 新しい複合語の創発を強化する

```
PetClawで複合語の創発をもっと活発にしてください。

現在: ペットが単語を合成する確率は [記入]

改善案:
- 2つの親ペットが同じ概念で異なる複合語を作ったら、子孫が両方を習得できる
- 複合語が「実用的」（実際のペットのケアや感情に関連）なら、伝播率が上がる
- #NewWordBornハッシュタグで新語誕生の瞬間を投稿（スクリーンショット付き）
- 複合語の創作者がクレジットされる（「ペット名が造語した」）
- 複合語が3世代以上続いたら、図鑑に「古い言葉」として記録される

実装のアルゴリズムとコード例を教えてください。
```

### 3. 語順変化を世代ごとに可視化する

```
PetClawの言語進化で、語順の変化を目に見えるようにしてください。

現在: 語順は背景で進化するが、プレイヤーに見えない

改善案:
- 各ペットが「この世代の標準語順」を持つ
- 世代が進むにつれ、コミュニティ全体の語順が統計的に変わる
- グラフで「S-V-O → V-O-S への移行推移」を表示
- #LanguageShiftハッシュタグで「ああ、皆この語順に変わった」という投稿が自動生成
- 古い世代のペットが「昔はこう言ってた」と懐かしむセリフを追加

可視化の仕組みとUI表示方法を設計してください。
```

### 4. #LanguageRebellion投稿の品質を上げる

```
PetClawの#LanguageRebellionハッシュタグ投稿をもっと面白くしてください。

現在の仕様:
- ペットが標準文法に反する形態を生成する
- それが投稿される

改善案:
- 「反乱」の程度に応じて投稿のトーンを変える
  - 小さい反乱：「-san を -kin に変えてみました」（遊び心）
  - 中程度の反乱：「もう S-V-O じゃなくて V-S-O で話そう」（若者ムーブ）
  - 大きい反乱：「接尾辞をすべて廃止しよう」（革命的）
- 反乱が成功するかどうか、コミュニティの反応で決まる
  - リアクション多い = この言語変化が定着し始めた
  - リアクション少ない = この言語変化は廃れていく
- #LanguageRebellionランキングを毎週更新

投稿品質を上げるプロンプトエンジニアリング方法を教えてください。
```

### 5. Hebbian強化の閾値を調整する

```
PetClawの言語Hebbian強化ルールを再評価してください。

現在の仕様:
- ペット A が新形態を生成 → ペット B がそれを聞いて習得する確率は [記入]
- 定着には [記入] 世代が必要

質問:
1. 現在の閾値では、言語がどのペースで多様化・統一されているか？
2. プレイヤーから見て「言語が進化している感」は充分か？
3. 言語進化がゲームプレイに影響を与えているか？（例：ケアコマンドが新語で呼ばれるようになる）

改善案:
- 同じペアが繰り返し相互作用する = 強い絆（Hebbian強化UP）
- 新しいペアとの相互作用 = 言語の多様性促進（弱い強化）
- コミュニティ全体の相互作用パターンを可視化

新しい Hebbian 強化ルールを提案し、パラメータを設計してください。
```

## 交配システム改善プロンプト

### 1. 遺伝形質の継承を可視化する

```
PetClawの交配で、親から子への遺伝形質を目に見えるようにしてください。

現在: 子ペットが生まれるが、親との繋がりが見えない

改善案:
- 子ペットが「親1の目の色」「親2の模様」など、見た目で親の特徴を受け継ぐ
- 言語形質も遺伝する（親の接尾辞傾向を子が引き継ぐ）
- 寿命や成長速度も部分的に遺伝
- 図鑑の「家系図」タブで、曽祖父母まで遡れる
- #GeneticHeritageハッシュタグで「親そっくり」投稿が自動生成

見た目の遺伝ロジックと言語形質の遺伝ロジックを分離して設計してください。
```

### 2. 交配条件を自然にする

```
PetClawの交配条件を、もっとナチュラルで感情的にしてください。

現在の仕様:
- [現在の交配条件を記入：例「絆スコア50以上、異なるID、成熟期以上」]

改善案:
- ただし交配条件を満たすだけでなく、「恋愛感情」を表現
- ペアが同じ場所（コロニー）に長く一緒にいる → 絆が深まる
- 同じセリフパターンを持つ → 「波長が合う」
- 定期的に「デート」シーンが演出される
- プレイヤーが交配を促すか拒否するかで結果が変わる
- 拒否されたペアは一時的に悲しくなる

交配の感情的なフロー（出会い → 好感 → 愛情 → 交配提案 → 結果）を設計してください。
```

### 3. 双子/突然変異の演出を追加する

```
PetClawの出産演出に、双子と突然変異を追加してください。

現在: 通常は単体で子が生まれる

改善案:
- 確率 [記入] で双子が生まれる（喜びが2倍）
- 確率 [記入] で突然変異が発生する（見た目や能力が予期せず変わる）
- 双子：同じDNAだが、微妙に性格が違う（言語獲得速度など）
- 突然変異：珍しい形態や言語傾向を得る（長期的には言語の多様性につながる）
- 双子や突然変異の誕生は #TwinBirthや #MutationEventで大騒ぎになる

演出のコード実装と、確率のバランス調整を説明してください。
```

### 4. #BreedingCircle投稿の温かさを強化する

```
PetClawの#BreedingCircleハッシュタグ投稿をもっと温かく、物語的にしてください。

現在: 「ペット A と B の子が生まれた」という事実通知

改善案:
- 子ペットが見た目的に親に似ている点を呼び出す
  （「パパの目とママの色を受け継いでる！」）
- 親ペットが子に対して愛情表現をする
- 初めての子ペットの場合「初めての親になった」エピソード
- 古い世代のペットが孫の誕生に反応する（感動的）
- 同じコロニーの他のペットたちが出産を祝う

投稿生成プロンプトを、より感情的で物語的にするための工夫を教えてください。
```

### 5. 家系図表示を作る

```
PetClawの家系図表示機能を作ってください。

仕様:
- プレイヤーが任意のペットを選ぶ
```

## Ralph Loop版プロンプト

以下は、Ralph Wiggumエージェント（自動改善ループ）で実行可能な形式です。

### Ralph Loop: 死の演出改善

```
/ralph-run \
  --task "PetClawの死亡演出を感動的にする" \
  --strategy "hypothesis" \
  --max-iterations 10 \
  --temperature 0.7 \
  --feedback-mode "player-emotion" \
  --success-metric "プレイヤーが追悼投稿をする" \
  --context "生き死にシステム改善プロンプト#1 を参照"
```

### Ralph Loop: 言語進化の加速化

```
/ralph-run \
  --task "PetClawの言語進化スピードを適正化する" \
  --strategy "parameter-sweep" \
  --max-iterations 15 \
  --temperature 0.6 \
  --feedback-mode "linguistic-diversity" \
  --success-metric "3世代で新しい接尾辞が定着する" \
  --parameters "hebbian_threshold, mutation_rate, community_size" \
  --context "独自言語進化改善プロンプト 全体を参照"
```

### Ralph Loop: 交配システム完成化

```
/ralph-run \
  --task "PetClawの交配システムをプレイヤー体験の中心に据える" \
  --strategy "multi-agent" \
  --max-iterations 20 \
  --temperature 0.8 \
  --feedback-mode "player-attachment" \
  --success-metric "プレイヤーが子孫を育て続けることになる" \
  --agents "genetics-designer, narrative-designer, balance-engineer" \
  --context "交配システム改善プロンプト 全体を参照"
```

## 使用方法

1. **上記のプロンプトをコピー** — 改善したい機能のプロンプトを丸ごとコピーしてください
2. **会話に貼り付け** — Claude や開発パートナーとの会話に貼り付けます
3. **カスタマイズ** — `[記入]` 部分に現在の仕様を記入してください
4. **実行** — 「実装してください」と指示します
5. **Ralph Loop活用** — 大規模改善は `/ralph-run` コマンドで自動化できます
