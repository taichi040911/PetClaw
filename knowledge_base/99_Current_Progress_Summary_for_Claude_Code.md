# KB99: Claude Codeに現状のサービス開発進捗を解説させる方法
**バージョン**: 2026年4月最新版
**対象**: 非エンジニア向け（Claude Cowork Projects連携）
**前提KB**: KB00 (PetClaw概要), KB88 (非エンジニア開発ガイド)

---

## 1. 基本の考え方

Claude Codeはフォルダ内の全ファイルを読み込めるので、以下の3つをしっかり与えると現在の進捗を正確に把握・解説してくれます：

- **Handoff Document**（現状まとめファイル）
- **CLAUDE.md**（プロジェクトの基本ルール）
- **Knowledge Baseフォルダ**（これまでのMDファイル群）

---

## 2. すぐに実行できる手順（おすすめ順）

### 手順1: Coworkで「現状まとめ（Handoff）」を作成させる（一番重要）

Claude Cowork（または通常チャット）で以下の指示をそのまま貼ってください：

```
私は非エンジニアです。
現在のPetClawプロジェクトの開発進捗を、Claude Codeがすぐに理解できるように詳細にまとめた「Handoff_PetClaw_Current_Status.md」を作成してください。

以下の内容を必ず含めて：
- これまでに決まった主な設計（生物生態系、生き死に・交配システム、PetBook UI、独自言語進化、感情連動など）
- 完成済みの機能とファイル一覧
- 現在進行中の機能
- 未実装・改善が必要な部分
- Ralph LoopやAgent Teams、MCPの現在の設定状況
- 次に優先して取り組むべきタスク3つ

Markdown形式で、Claude Codeに読み込ませやすいように明確に書いてください。
プロジェクトフォルダに保存できる形に。
```

→ これで `Handoff_PetClaw_Current_Status.md` というファイルが生成されます。

### 手順2: Claude Codeで現状を解説させる

Claude Codeを起動し、以下の指示を貼ってください：

```
プロジェクトフォルダ内のすべてのファイルを読み込んでください。
特にHandoff_PetClaw_Current_Status.mdとCLAUDE.md、Knowledge Baseフォルダの内容をしっかり理解してください。

現在のPetClaw開発の進捗状況を、非エンジニアの私でもわかりやすい言葉で解説してください。

以下の点を必ず含めて：
- 現在どこまでできているか（完成済み機能一覧）
- 特に良くできている部分
- まだ改善・実装が必要な部分
- 次に優先して取り組むべきこと（3つ以内にまとめて）
- Ralph LoopやAgent Teamsを活用した次のアクション提案

ステップごとに丁寧に説明してください。
```

### 手順3: 定期的に更新させる

開発が進んだら、Coworkで以下の指示を出すだけでHandoffを更新できます：

```
現在の開発状況を反映して、Handoff_PetClaw_Current_Status.mdを最新版に更新してください。
```

---

## 3. 非エンジニア向けTips

- **頻度**: 週に1〜2回、この手順を実行すると状況が整理されやすい
- **確認習慣**: Claude Codeが解説した後、「この解説で合ってる？ 間違ってる部分があれば教えて」と聞いて調整
- **Ralph Loopとの組み合わせ**: 解説後にすぐに改善ループを回したい場合は、解説の最後に「この解説を基にRalph Loopで改善を始めて」と追加指示
- **ファイル整理**: Knowledge BaseのMDファイルは番号付き（例: `73_〜`、`98_〜`）で管理するとCodeが読み込みやすい

---

## 4. すぐに試せるフル指示（Claude Code用）

```
プロジェクトフォルダをすべて読み込んでください。
Handoff_PetClaw_Current_Status.mdがあれば優先的に理解してください。

PetClawの現在の開発進捗を、私（非エンジニア）でもわかりやすい言葉で詳しく解説してください。
完成済み機能、進行中の機能、改善が必要な点、次にやるべきことを明確に整理して。
最後に、Ralph Loopを使って次に進めるための具体的な指示も提案してください。
```

この方法で、Claude Codeがあなたの代わりに現状をしっかり整理・解説してくれます。
