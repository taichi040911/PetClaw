# 生物生態系・体調変化・生き死に・交配 統合設計ガイド
**PetClaw Knowledge Base — 2026年3月最新版**

## 1. コンセプト概要（3作品の本質を生物生態系として統合）

- **たまごっち**: 「世話の結果が命に直結する」緊張感と愛着
- **ポケモン**: 「努力と環境で進化・収集する」成長のドラマと多様性
- **デジモン**: 「訓練と関係性で分岐進化する」パートナーシップの深み

### PetClaw版の生物生態系
- ペットは「生き物」として、環境・体調・生き死に・交配がリアルに連動
- AtoA会話・性格・感情が生態系に影響を与え、「自分の行動が命と関係性を変える」強いエージェンシーを生む
- スタイリッシュ2Dピクセルで表現し、粒子エフェクト + HSV色計算で視覚的に「生命の変化」を感じさせる

## 2. 詳細メカニクス設計

### 2.1 生物生態系（Environment System）
- **環境の種類**: 森（成長速め・好奇心↑）、海（特殊進化・冷静↑）、廃墟（ホラー寄り・勇敢↑）など
- **影響**: 環境ごとに餌の効果・体調変化・進化ルートが異なる。プレイヤーが「環境を変更」できる（移動アクション）
- **AtoA連動**: ペット同士で「この環境いいね！」と会話が発生
- **視覚**: 背景 + 粒子エフェクトが環境ごとに変化（HSVで色調調整）

### 2.2 体調変化（Body Condition System）
**主要ステータス:**
- Hunger（空腹）: 減衰速め。餌で回復
- Health（体力・免疫）: 病気リスク
- Energy（活動力）: 遊び・訓練で消費
- Mood（気分全体）: 感情システムと連動
- Age（年齢）: 徐々に増加し、体調変化が速くなる

**変化のルール:**
- 時間経過で自然減衰（Ebbinghaus曲線模倣）
- 世話アクションで即時変化 + 感情影響
- 放置で体調悪化 → 病気・弱り演出

### 2.3 生き死にシステム（Life & Death Mechanics）
- **死のリスク**: Hunger/Healthが長期間0になると「弱っていく」演出 → 死
- 死の悲しみをAtoA会話で表現（他のペットが悲しむ）
- 蘇生可能（特別ケアやAtoA協力で）
- **老化**: Ageが上がると体調変化が速くなり、特殊進化ルート開放
- **愛着強化**: 死のリスクがあるからこそ、世話をしたくなる緊張感と達成感

### 2.4 交配システム（Breeding Mechanics）
- **条件**: 2匹以上のペットが一定のAffection + Health + 相性（性格相性）を満たす
- **結果**: 新しいペット誕生（遺伝: 親の性格・Traits・記憶の一部を確率で継承）
- **AtoA連動**: 交配時にペット同士で「家族になろう！」会話 + 特別粒子演出
- **ポケモン風**: 新ペットに親の特徴が反映され、収集要素を強化
- **デジモン風**: 交配で進化ルートが追加開放

## 3. Godot 4.x 実装のポイント
- EcosystemManager.gd: 環境・体調・生き死に・交配を一元管理
- CareAction連動: 各世話アクションが生態系に影響を与える
- 視覚: 粒子エフェクト + HSV色計算で体調・生き死にを表現
- Karpathy Loop: 「愛着の深さ」「生態系のバランス」「交配の面白さ」を自動最適化
