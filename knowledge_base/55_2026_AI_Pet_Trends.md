# 55. 2026年 AIペットトレンドまとめ

## 1. 主要トレンド（2026年3月時点）

### 物理成長型AIペット（最大のブレイク）
- **Sweekar (Takway AI)**: CES 2026デビュー。卵型デバイスから孵化、物理的に成長、MBTI風性格 + AI記憶 + 自律行動。オフライン時「冒険」して報告。レベル51以上で不死。
- **特徴**: 物理デバイス + AIハイブリッド。触れる・抱きしめる体験。AtoAペット間交流も計画中。

### 感情表現豊かなロボットペット
- **Ollobot (OlloNi)**: ふわふわ外見、感情表現（目・音・動き）が強い。家族ルーチン学習、帰宅挨拶。
- **LilMilo (Ecovacs)**: Bichon Frisé風ロボット。声認識・習慣学習・感情表現。
- **Cocomo & INU (Ludens AI)**: 「生産性ではなく存在感」。進化する性格と記憶で関係性構築。

### 全体の方向性
- **感情知能（Emotional Intelligence）** が最重要
- AtoA要素の増加（ペット同士の自律交流）
- コスト意識（ハイブリッド設計: ローカルルール + LLM）

## 2. PetClawへの具体的な活かし方

| トレンド元 | PetClaw適用 |
|-----------|-----------|
| Sweekar | 卵孵化→物理成長アニメ、オフライン自律行動→帰還報告 |
| Ollobot / LilMilo | 感情表現の豊かさ（目の変化・動き）、粒子+HSV色計算 |
| Cocomo | 「存在感」重視、AtoA会話を自然に発生させる |

### 実装優先事項
1. AtoA会話: 背景会話 + プレイヤー対話（性格+感情プロンプト）
2. 進化演出: HSV拡張計算で性格→粒子量・色・派手さを動的変化
3. コスト対策: 日常会話はローカルルールベース、重要イベントだけClaude API
