## 3. ループが止まったときの対処法・デバッグTips

### 止まる主な原因と対処

| 状況 | 原因 | 対処法 |
|------|------|--------|
| エラーが出た | コードにバグがある | 「エラーの内容を教えて」と聞き、Claudeに修正を依頼 |
| completion-promiseが出ない | 条件が厳しすぎる | より明確なpromiseに変更（例: `"PETBOOK_DONE_V2"`） |
| ループが長すぎて止まらない | iterationsが多い/条件未達 | `/cancel-ralph` と入力して強制停止 |
| コストが気になる | ループ回数が多い | `--max-iterations` を8〜10に減らす |
| 結果が微妙 | 指示が曖昧 | ループ終了後に「この結果を基に、もう一度改善して」と新しい指示を出す |

### デバッグ時に使える指示例

```text
Ralph Loopが止まったようです。原因を教えてください。
その後、改善したバージョンをもう一度ループで試してください。
```

### 段階的リカバリー手順

1. **まず状況確認**: 「今の状態を教えてください」
2. **エラー確認**: 「エラーが出ていたら見せてください」
3. **巻き戻し判断**: 「最後の正常な状態に戻すべきですか？」
4. **再実行**: 範囲を狭めて「この部分だけもう一度ループして」
