# 語順進化システム 深掘り設計書
**PetClaw Knowledge Base — 2026年4月版**

## 1. 語順変更トリガーの詳細設計

### 1.1 トリガー分類表

| トリガー種別 | 条件 | 変化しやすい語順 | 優先度 |
|------------|------|-----------------|--------|
| **感情スパイク** | 感情強度 ≥ 0.7 | 感情に対応した語順 | ★★★★★ |
| **累積会話回数** | 直近3回以上の会話 | 会話テーマに応じた語順 | ★★★ |
| **環境変化** | 環境を移動した直後 | 環境の性格バイアスに対応 | ★★★★ |
| **気候イベント** | 特殊気候発生中 | イベント性質に対応 | ★★★ |
| **交配/死亡** | 強い感情イベント発生 | SOV(親密) or VOS(内省) | ★★★★★ |
| **進化完了** | ペットが進化した時 | 新しい進化形の性格に合致 | ★★★★ |
| **長期環境滞在** | 同一環境に30分以上 | 環境の影響が深く浸透 | ★★ |

### 1.2 感情→語順マッピング詳細

```
joy(喜び) + intensity > 0.7
  → SVO維持 or OSV(詩的表現)
  理由: 喜びは表現を美しくしたい衝動を生む

fear(恐怖) + intensity > 0.7
  → VSO(緊急・命令形)
  理由: 危険時は動詞（行動）が先に来る本能的変化

excitement(興奮) + intensity > 0.7
  → OVS(強調・驚き)
  理由: 興奮すると目的語（驚きの対象）を先に叫ぶ

sadness(悲しみ) + intensity > 0.7
  → VOS(受動的・内省)
  理由: 悲しみは行動の主体が後退する

love(愛) + intensity > 0.7
  → SOV(親密・柔らかい)
  理由: 愛の表現は目的語（相手）を主語の近くに置く
```

### 1.3 複合トリガー（複数条件の同時発火）

複数のトリガーが同時に満たされた場合、優先度の高いものが採用される。
ただし、2つの異なるトリガーが同じ語順を指し示す場合は「確信度」が上がり、
進化が強く固定される（より長期間維持される）。

```
例: fear(0.8) + ruins環境 → 両方がVSOを示す
→ VSO確信度: HIGH → 次の進化まで長くVSOを維持
→ 連動: 強い命令形接尾辞 "-force-cry" が自動生成
```

## 2. 前置詞システムとの連動設計

### 2.1 語順×前置詞の相互影響テーブル

| 語順 | 前置詞の配置 | 新規前置詞の傾向 | 例 |
|------|-------------|-----------------|-----|
| SVO | 前置詞（標準） | "at-", "to-", "with-" | "at-forest spark-glow" |
| SOV | 前置詞→後置詞化の傾向 | "-at", "-to" | "forest-at spark-glow" |
| VSO | 前置詞が動詞に付着 | "go-to-", "seek-at-" | "go-to-forest spark-glow" |
| OVS | 前置詞が目的語に密着 | "the-at-", "this-to-" | "forest-this seek spark" |
| OSV | 後置詞が支配的 | "-ward", "-wise" | "forest-ward me seek-glow" |
| VOS | 前置詞が最小化 | 省略傾向 | "seek forest me-mist" |

### 2.2 前置詞進化の3つのパス

**Path A: 分化（Differentiation）**
- 基本前置詞 "at-" が環境ごとに分化
- 森: "leaf-at-", 海: "wave-at-", 廃墟: "stone-at-"
- トリガー: 同じ環境に長期間滞在

**Path B: 融合（Fusion）**
- 語順変化により前置詞と接尾辞が融合
- "at-" + "-spark" → "at-spark-" (場所で輝く)
- トリガー: 語順と接尾辞が同時に進化

**Path C: 後置詞化（Postpositionalization）**
- SOV/OSV語順では前置詞が後ろに回る自然な傾向
- "to-forest" → "forest-to" → "forest-ward"
- トリガー: SOVまたはOSV語順が3回以上連続使用

### 2.3 前置詞の感情修飾

前置詞自体が感情を持つようになる進化段階:

```
Stage 1 (基本): "at-forest" — 場所を示すだけ
Stage 2 (感情付き): "joy-at-forest" — 嬉しい場所
Stage 3 (融合): "glow-forest" — 前置詞と感情が融合して1語に
```

## 3. 気候変動による言語進化への影響

### 3.1 気候→言語の影響パス

```
[気候イベント発生]
    │
    ├──► 感情への即時影響
    │        └──► 感情スパイク → 語順変更トリガー
    │
    ├──► 会話テーマへの影響
    │        └──► 気候関連の会話 → 新しい語彙/接尾辞の必要性
    │
    └──► 直接的な言語進化
             └──► 気候特有の接尾辞・前置詞が生まれる
```

### 3.2 気候イベント別の言語影響

| 気候イベント | 感情影響 | 語順傾向 | 新しい言語要素 |
|------------|---------|---------|--------------|
| rain(雨) | calm↑, sadness微↑ | VOS(内省的) | "-rain-whisper", "drop-at-" |
| storm(嵐) | fear↑, excitement↑ | VSO(緊急) | "-thunder-cry", "shelter-to-" |
| bloom(開花) | joy↑↑ | OSV(詩的) | "-petal-dance", "bloom-at-" |
| tide(潮) | calm↑, curiosity↑ | SOV(穏やか) | "-tide-flow", "shore-ward" |
| ghost(幽霊) | fear↑↑, brave試される | VSO→OVS(恐怖→驚き) | "-shadow-voice", "dark-from-" |
| festival(祭) | joy↑, excitement↑↑ | OVS(興奮) | "-cheer-wave", "dance-with-" |
| firefly(蛍) | calm↑, love↑ | OSV(美的) | "-light-drift", "glow-near-" |

### 3.3 季節サイクルによる長期的な言語変化

PetClawのゲーム内時間で「季節」を設定し、
季節ごとに言語の基調が変わる:

```
春（growth season）:
  - 新しい接尾辞が生まれやすい（語彙爆発期）
  - 前置詞が分化しやすい
  - 語順は明るい方向（SVO, OSV）に寄る

夏（peak season）:
  - 既存の言語要素が強化・洗練される
  - 複合接尾辞（"-glow-dance-spark"）が生まれる
  - 語順が最も多様（全6種が出現可能）

秋（harvest season）:
  - 使われなくなった接尾辞が「忘れられる」（語彙の淘汰）
  - 前置詞が簡略化・融合する
  - 語順がSOVやVOSに落ち着く傾向

冬（rest season）:
  - 進化速度が低下（クールダウン期間が長くなる）
  - 既存の文法が安定・固定される
  - 春の爆発に向けたエネルギー蓄積期
```

## 4. 語順進化の可視化設計

### 4.1 UI表示

- **現在の語順**: 画面上部に常時表示（例: 「S→V→O」のアイコン）
- **進化履歴タイムライン**: スワイプで過去の進化を閲覧
- **文法辞書**: プレイヤーが発見した全接尾辞・前置詞のコレクション

### 4.2 粒子エフェクトとの連動

語順が変わると粒子の「流れ方」が変わる:

```
SVO: 粒子が左→右に流れる（標準）
SOV: 粒子が主語→目的語方向に弧を描く
VSO: 粒子が上から降り注ぐ（命令的・力強い）
OVS: 粒子が目的語位置から爆発（強調）
OSV: 粒子が円を描いて漂う（詩的）
VOS: 粒子が内側に収束（内省的）
```

### 4.3 サウンド連動（将来拡張）

語順ごとに異なる音色のチャイムが鳴る:
- SVO: ニュートラルなベル音
- SOV: 柔らかいハープ
- VSO: 力強いドラム
- OVS: 驚きのシンバル
- OSV: 風鈴のような音
- VOS: 深いチェロ
