# 世話アクション 詳細設計ガイド
**PetClaw Knowledge Base — 2026年3月最新版**

## 1. 全体コンセプト

目標: 「タップ一つで即反応があり、ペットが本当に変わる」という強いエージェンシーと愛着を生む。

たまごっちの「可愛い即時フィードバック」を保ちつつ、現代的にアップデート:
- 各アクションが性格・感情・記憶に即時影響を与える
- AtoA会話が世話の結果として自然に発生（例: 餌をあげた後、ペット同士で喜びを共有）
- 粒子エフェクト + HSV色計算で視覚的に「感情の変化」が伝わる
- Karpathy Loopで「可愛さ・バランス・自然さ」を自動数百改善

## 2. 世話アクション一覧と詳細設計

### Feed（餌やり）
- **UI**: 下部メニューに可愛い餌アイコン。タップで餌を投げるアニメ
- **即時反応**: ペットが嬉しそうに食べる（DeeVid生成アニメ + 粒子: ハート + 食べ物粒子）
- **影響**: Hunger ↓, Affection ↑, Excitement微増
- **性格連動**: Curiousが高いと「新しい味に興味津々」の特別会話発生
- **AtoA連動**: 食べた後、ペット同士で「美味しいね！」と会話
- **粒子設定**: 明るい暖色グラデーション（HSVで性格色反映）。量はAffectionに比例

### Clean / Bath（掃除・お風呂）
- **UI**: シャワーやブラシアイコン。タップでペットが喜ぶアニメ
- **即時反応**: ペットがキレイになってリラックス（粒子: キラキラ + 水しぶき）
- **影響**: Health ↑, Calm ↑, Fear微減
- **性格連動**: Loyalが高いと「ありがとう」の感謝会話
- **AtoA連動**: 掃除後、ペット同士で「スッキリしたね」と共有
- **粒子設定**: 柔らかい青白グラデーション。落ち着きを強調

### Play（遊び）
- **UI**: ボールやおもちゃアイコン。タップでペットが飛び跳ねる
- **即時反応**: ペットが楽しそうに遊ぶ（粒子: 星 + 動きの軌跡）
- **影響**: Curiosity ↑, Excitement ↑, Happiness ↑
- **性格連動**: Braveが高いと「もっと激しく遊ぼう！」提案
- **AtoA連動**: 遊び中にペット同士で競争や協力が発生
- **粒子設定**: 明るい多色粒子。好奇心が高いと量が増える

### Train / Exercise（訓練）
- **UI**: ダンベルやランニングアイコン
- **即時反応**: ペットが頑張るアニメ（粒子: エネルギー波）
- **影響**: Brave ↑, 進化ポイント蓄積
- **性格連動**: Loyalが高いと「一緒に強くなろう」の励まし会話
- **AtoA連動**: 訓練後、ペット同士で「次は勝とうね」と励まし合い
- **粒子設定**: 力強い赤オレンジグラデーション。勇敢さで派手さを調整

### Medicine / Care（薬・回復）
- **UI**: 薬瓶アイコン
- **即時反応**: ペットが元気になる（粒子: 柔らかい癒しの光）
- **影響**: Health ↑, Fear微減, Calm ↑
- **性格連動**: Affectionが高いと「ありがとう」の温かい反応
- **AtoA連動**: 回復後、ペット同士で「大丈夫？」と心配し合う
- **粒子設定**: 優しい緑〜白グラデーション

## 3. 共通の技術的実装ポイント

- **即時フィードバック**: タップ → 0.2秒以内にアニメ + 粒子 + 感情更新
- **性格・感情連動**: 各アクションで`get_personality_modifier()`と`get_emotion_modifier()`を呼んで影響を計算
- **AtoAトリガー**: 世話後60%の確率でペット同士の会話が発生（自然さを重視）
- **粒子連動**: HSV色計算で性格色を反映。感情が高いと粒子量・速度が増す
- **Karpathy Loop**: 各アクションの「可愛さ」と「愛着スコア」をMCPでテスト → 自動改善

## 4. 生態系統合版の追加要素

- **生態系連動**: 環境ごとの餌で効果が変わる（森の木の実 → Energy ↑ + Curiosity ↑）
- **体調変化**: リアルな健康状態（病気・ストレス・老化）と連動
- **生き死に連動**: 世話不足 → 体調悪化 → 死リスク → 愛着強化のループ
- **交配連動**: 十分な世話が交配条件の基盤
