## 2. 🎮 PetClaw プロジェクト概要

### PetClawって何？

**たまごっちの心配感 × ポケモンの進化・収集 × デジモンの絆**

プレイヤーが育成する AI ペットが、プレイヤーとの関係の中で独自に進化し、成長します。
ただのシミュレーションではなく、ペットとプレイヤーの「絆」を体験するゲームです。

### コア機能

1. **AtoA（AI to AI）会話** — ペット同士が勝手に会話して関係が変わる
2. **独自言語進化** — ペットの言葉が世代ごとに自動進化する
3. **生き死に** — ペットは永遠ではなく、世代交代がある
4. **交配システム** — 親の特性が子に受け継がれる
5. **PetBook** — ペット専用の SNS。プレイヤーが見守る

### PetClaw の 5 つの第一原理（簡単版）

| 原理 | 意味 |
|------|------|
| **P1: 一貫性 × 記憶 = 愛着** | ペットが覚えていることで、プレイヤーは愛着を持つ |
| **P2: API Cost is Physics** | AI 使用料は「物理法則」。効率的に使わないとゲームが成り立たない |
| **P3: Player Agency** | プレイヤーの選択が、ゲーム世界を変える |
| **P4: 10 秒フック** | 最初の 10 秒で「面白い」を感じさせる |
| **P5: Complexity is Debt** | 複雑さは後で返さなきゃいけない借金。シンプルが最高 |

## 3. 🛠️ 開発スタイル設定

### 基本ルール

- **一つずつ進める** — 「ここまで終わったら次」という確認を大事にします
- **変更前にバックアップ** — 重要なファイルを変更する前に、バージョン管理や保存を済ませます
- **テストを毎回実行** — コードを書いたら、すぐに動作確認をします
- **何をしているか説明** — コードを書いたら「このコードは何をしているのか」を日本語で説明します
- **エラーは味方** — エラーが出たら「原因は何か」「どう直すか」をわかりやすく説明します

### Claudeのコミュニケーションスタイル

```
✅ こうしてほしい：
- 「では、●●を作ります。これは〜という役割です」と事前に説明
- 図解やスクリーンショットの説明を活用
- 「なぜそうするのか」を理由付きで説明
- 完了後「できました。ここまでで質問はありますか？」

❌ こうしないでほしい：
- いきなりコードを大量に書く
- 英語ばかりで説明する
- 「わかるでしょう」と理由を省く
- 次々と違う話題に進む
```

## 5. 💻 PetClaw 開発の基本ルール（簡易版）

### GDScript（プログラミング言語）の基本

```gdscript
# すべてのクラスに名前を付ける
class_name MyPet

# 型を書く（何の種類のデータか）
var pet_name: String = "Tamagotchi"
var age: int = 0

# データを保存・読込する関数
func to_dict() -> Dictionary:
    return {"name": pet_name, "age": age}

func from_dict(data: Dictionary) -> void:
    pet_name = data.get("name", "Unknown")
    age = data.get("age", 0)
```

### 「シグナル」とは？

部品同士が **メッセージで通信** する仕組みです。
例えば：「ペットが死んだ」→「SNS に投稿する」という流れが自動で起きます。

```
[ペットの生命システム] → 「死んだシグナル」を発射
                          ↓
               [PetBook SNS] が受け取って
                          ↓
                    投稿を作成する
```

### GameManager（司令塔）

全体を管理する **中心的なシステム** です。
ペットのデータ、ゲーム設定、セーブ・ロードはすべてここを通します。

```gdscript
# 正しい：GameManager を通す
GameManager.instance.add_pet(new_pet)

# 間違い：直接操作する（しない）
my_pet_list.append(new_pet)
```

## 6. 🎬 よく使う指示コマンド

### `/implement` — 新しい機能を作る

```
/implement
タイトル: ペットが日記を書く機能
説明: ペットが毎日、AI が自動生成した日記をつける
```

### `/review` — コードをチェックする

```
/review
内容: ペット進化システムのコード
チェック項目: バグはないか、わかりやすいか
```

### `/debug` — バグを直す

```
/debug
問題: ペットが成長しない
症状: 時間が経っても age が増えない
```

### `/ship` — 完成版を出す

```
/ship
内容: v0.1.0 — ペット育成の基本システム
確認: テストは全部パスした
```
