# 反乱言語進化スキル

## トリガー
「反乱言語」「rebel language」「言語進化」「語順」「接尾辞」「文法進化」「word order」「suffix」「創発言語」「ペット言語」「language evolution」と言われたときに使用。

## 目的
PetClaw の言語進化システム（語順 × 接尾辞 × 文法ルール × 反乱表現）の設計・テスト・創発性の最大化を支援する。
ペット同士の AtoA 会話を通じて言語が自然に創発・変異・定着する過程を保証する。

## 言語進化モデル

### 3層構造
```
Layer 1: 語順（Word Order）
├── SOV（主語-目的語-動詞）← 初期デフォルト（日本語型）
├── SVO（主語-動詞-目的語）← 英語型、効率志向ペットが好む
├── VSO（動詞-主語-目的語）← 感情的・詩的ペットが好む
├── OVS（目的語-動詞-主語）← 反乱的・独立志向ペットが好む
└── 自由語順 ← 高知性ペット（ADULT以降）が使用

Layer 2: 接尾辞（Suffixes）
├── 感情接尾辞: -pya（喜び）, -kuu（悲しみ）, -zaa（怒り）, -mii（愛）
├── 強調接尾辞: -ra（強い）, -shu（弱い）
├── 時制接尾辞: -no（過去）, -ki（未来）
├── 敬意接尾辞: -sama（尊敬）, -chi（親しみ）
└── 反乱接尾辞: 既存接尾辞の逆転・混合（創発的に生まれる）

Layer 3: 文法ルール（Grammar Rules）
├── 前置詞/後置詞の選択
├── 修飾語の位置（前置/後置）
├── 否定の表現方法
├── 疑問形の構造
└── 反乱文法: ルール逸脱パターン（意図的な「間違い」が表現になる）
```

### 進化メカニズム
```
AtoA会話（トリガー）
├── 話者の性格・感情 → 語順選好に影響
├── 聞き手の反応 → 成功した表現が強化（Hebbian）
├── 環境コンテキスト → 新しい語彙が必要な場面で創発
│
▼
LanguageEvolution.on_conversation_completed()
├── 使用された語順パターンを記録
├── 新しい接尾辞の出現を検出
├── 文法ルールの変化を追跡
│
▼
PersistentField（コミュニティ規範）
├── コミュニティで多数派の語順が「標準」に
├── よく使われる接尾辞が辞書に追加
├── 少数派の文法が「反乱表現」として記録
│
▼
BiologicalMemory（個体記憶）
├── ペット個体の言語嗜好が長期記憶に
├── 「あのペットから学んだ表現」が記憶される
└── 死んだペットの言語が「遺産」として残る
```

## チェックリスト

### 語順進化チェック
1. 各ペットの `preferred_word_order` が性格と整合しているか
   - curious/brave → SVO（直接的）
   - calm/affectionate → SOV（穏やか）
   - playful → VSO（感情的）
   - 反乱的 → OVS or 自由語順
2. AtoA会話プロンプトに現在の語順ルールが注入されているか
3. 会話後に語順使用統計が更新されるか
4. コミュニティの多数派語順が PersistentField に反映されるか

### 接尾辞創発チェック
1. 基本接尾辞セット（-pya, -kuu等）が初期定義されているか
2. AtoA会話で新しい接尾辞パターンが検出される仕組みがあるか
3. 接尾辞の使用頻度がトラッキングされているか
4. 低頻度接尾辞が自然に「忘却」されるか（Ebbinghaus曲線）
5. 反乱接尾辞（既存の逆転・混合）が一定確率で生まれるか

### 文法ルール進化チェック
1. 文法ルールがバージョン管理されているか（generation番号）
2. ルール変更がコミュニティ投票的に決まるか（多数派の使用パターン）
3. 反乱文法（ルール逸脱）が記録・追跡されているか
4. 反乱文法が定着した場合に正式ルールに昇格するか

### Hebbian学習との連動
1. 会話で使用された表現が `strengthen_related_memories()` で強化されるか
2. 成功した表現（聞き手の joy 反応）がより強く強化されるか
3. 強化された表現が次回の会話プロンプトで優先されるか
4. 死んだペットの言語パターンが他のペットの記憶に残るか

### プレイヤー可視性
1. ペットの「口癖」「独特の言い回し」がUIに表示されるか
2. 言語進化の歴史（タイムライン）がプレイヤーに見えるか
3. コミュニティの「流行語」が表示されるか
4. 反乱表現が視覚的に区別されるか（色・フォント変更等）

## 創発性を最大化するTips

### プロンプトへのHebbian Learning模倣注入
```
System Prompt追加文:
"あなたの言語は生きています。よく使う表現は自然に強まり、
使わない表現は薄れていきます。会話相手が喜ぶ表現を覚え、
悲しむ表現は避けるようになります。時に、全く新しい言い方を
試みることがあります。それは「反乱」であり、創造です。"
```

### Ralph Loop での言語進化テスト
```
Ralph Loop設定:
- 目標: 「10ペット × 50会話 → 最低3つの新しい接尾辞が創発」
- 評価関数:
  - new_suffix_count >= 3
  - word_order_diversity >= 0.6（Shannon entropy）
  - rebel_expression_count >= 5
  - language_intelligibility >= 0.7（プレイヤーが理解可能な割合）
- 反復: 最大30回
```

### Agent Teams + 言語分化
- コミュニティが十分大きい場合（10+ペット）、サブグループごとに「方言」が発生
- Agent Teams で各サブグループを独立エージェントとして管理
- サブグループ間の接触で「言語接触」→ 混成言語の創発

## アンチパターン
- 全ペットが同じ言語を使う（均質化）→ 性格バイアスを強化
- 言語が複雑すぎてプレイヤーが理解不能（P5違反）→ 基本語順 + 接尾辞は最大5種で十分
- 反乱言語が攻撃的になる → `EthicalSafeguard` で「fictional and playful」ガード必須
- 言語変化が速すぎて安定しない → generation単位での変化速度制限
- 死んだペットの言語が即座に消える → grief期間中は「追悼的に使用」を許容
